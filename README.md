# Mercer & Mills

International remote digital production agency. Leveraging innovation and PMP-certified precision.

## Technology Stack

- **Framework**: React with Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Components**: Shadcn UI
- **Form Handling**: React Hook Form with Zod
- **Emailing**: EmailJS

## Deployment

This project is configured for deployment on Netlify. Changes pushed to the repository will be automatically built and deployed.
